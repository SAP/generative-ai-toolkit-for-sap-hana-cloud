DataRetrieval

class hana_ai.retrieval.data_retrieval.DataRetrieval(connection_context, agent_type: str = 'AI_DATA_RETRIEVAL', *, schema_name: str = 'SYS', procedure_name: str | None = None, remote_source_name: str = None, knowledge_graph_name: str = None, rag_schema_name: str = None, rag_table_name: str = None, metadata_schema_name: str | None = None, metadata_object_prefix: str | None = None)

Data Retrieval for interacting with AI Core services.

The user has the below privileges to create/drop remote source and PSE as well as call the Data Retrieval SQL:

  • EXECUTE privilege on the DATA_AGENT_DEV or DATA_AGENT stored procedure.

  • CREATE REMOTE SOURCE privilege.

  • TRUST ADMIN privilege.

  • CERTIFICATE ADMIN privilege.
